The personal log is the highest-leverage asset over the 10 weeks. Maintain it weekly,
not retroactively.

## Tony Wood's framework (graders' implicit lens)

Proposal and main pitch should explicitly use:

- **Funding-deck template**: Title → Problem → Solution → Market Opportunity → Product → Business Model → Traction → Market Strategy → Competitive Analysis → Financial Projections → Team → Use of Funds → Ask → Contact.
- **Mission** with a £100m bar (VC-fundable scale).
- **TAM / SAM / SOM** for market sizing.
- **Beachhead customers** + personas for early adopters.
- **MVP** and **Product-Market Fit** as proof-of-concept goals.
- **Business Model Canvas** (problem, target market, solution, revenue, costs, competition, channels).
- **T-shirt sizing** for tasks: XS=3d, S=4–7d, M=8–12d, L=13–20d, XL=21–30d, XXL=30d+.
- **Kanban** columns: Backlog → Design → To-Do → Doing → Review → Done.
- **RACI matrix**: Responsible / Accountable / Consulted / Informed.
